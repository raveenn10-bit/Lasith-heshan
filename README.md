# LASITH HESHAN — The Digital Experience

A cinematic, mobile-first personal brand website for Lasith Heshan, designed and developed by Harsh Apex Digital Solutions.

## Included

- Responsive cinematic portfolio and original portrait treatment
- Fullscreen navigation, scroll reveals and reduced-motion support
- Verified Facebook and Instagram links
- Lightweight FAQ website assistant
- Playable **Lasith Run — Beyond Limits** Canvas game with local high score
- Accessible contact enquiry handoff
- SEO metadata, Person schema, sitemap and private-preview robots policy

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Before public launch

1. Replace `noindex,nofollow` in `index.html` with `index,follow`.
2. Change `robots.txt` from `Disallow: /` to `Allow: /`.
3. Replace the placeholder domain in `sitemap.xml` when the final domain is confirmed.
4. Add approved contact details and any verified video/project content.

No admin dashboard, paid API, analytics tracker or secret key is included.
